Data Retention Policy

Project AURA stores conversations and extracted memory tokens inside your local SQLite database (`data/aura.db`). No personal data is sold, monetized, or shared with third parties beyond the LLM inference requests made to your configured provider.

Permanent User Data Wipe (GDPR / Privacy Compliant)

Permanently purges all messages, memories, and profile data for a specific user ID. This action is irreversible.
