Data Retention Policy

Project AYLIN stores conversations and extracted memory tokens inside your local SQLite database (`data/aura.db`). No personal data is sold, monetized, or shared with third parties beyond the LLM inference requests made to your configured provider.

Permanent User Data Wipe (GDPR / Privacy Compliant)
